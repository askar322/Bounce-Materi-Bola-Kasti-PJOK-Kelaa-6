MPI PJOK KELAS VI — PAKET HOSTING ONLINE
========================================

ISI PAKET
- index.html : aplikasi MPI PJOK Bola Kasti. Semua HTML, CSS, JavaScript dan konten utama berada dalam satu file.

CARA A — NETLIFY (cara paling mudah)
1. Ekstrak ZIP ini ke komputer.
2. Buka https://app.netlify.com/drop
3. Seret folder yang berisi index.html ke area unggah.
4. Tunggu proses publikasi selesai. Netlify akan memberi URL publik untuk dibagikan kepada siswa.
5. Buka URL tersebut di ponsel atau komputer untuk menguji aplikasi.

CARA B — GITHUB PAGES
1. Masuk ke https://github.com dan buat repository baru, misalnya mpi-pjok-kelas-vi.
2. Unggah file index.html dari paket ini ke folder utama (root) repository.
3. Buka Settings > Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder /(root), lalu tekan Save.
6. Tunggu proses selesai. URL biasanya berbentuk https://NAMA-PENGGUNA.github.io/NAMA-REPOSITORY/.

CATATAN
- Paket ini siap diunggah ke hosting statis; file belum dipublikasikan ke internet dari sini.
- Hosting publik memerlukan akun/izin pengguna pada Netlify atau GitHub.
- Aplikasi berjalan sebagai situs statis dan tidak memerlukan server atau database.
- Fitur penilaian tersimpan dalam sesi browser; paket ini tidak mengirim nilai siswa ke database pusat.
- Uji semua menu, asesmen, simulasi, dan tampilan cetak sebelum digunakan di kelas.
